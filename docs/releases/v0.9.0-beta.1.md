# VeXArk 0.9.0-beta.1 — component-aware restore and ROM compatibility

This prerelease expands rooted Android backup and restore into a
component-aware, transactionally verified workflow while retaining conservative
handling for data that cannot be safely restored.

## Highlights

- Manifest v2 records typed CE, DE, external and OBB roots, component coverage,
  restore classes and per-component verification results.
- Restore now journals rooted app-data work, verifies BLAKE3 size/hash data,
  performs a read-back health check and rolls back failed transactions.
- Backup and restore cover wallpapers, contacts/call log merge, locale and
  conservative same-ROM theme overlay recovery.
- ROM identity and typed compatibility catalogs cover AOSP, Lineage, crDroid,
  Launcher3, Xiaomi dada, GameSpace and theme providers. Unknown provider keys
  remain archive-only or are ignored with an explicit reason.
- APK preflight authenticates chunks, object IDs, sizes and whole-file SHA-256
  before installation. The next verified APK can be staged while Android
  installs the current package, with installs still committed sequentially.
- The operation UI provides virtualized item state, detailed reports and a
  central repository-unlock path.

## Safety and reliability

- Incomplete shared/full scans cannot be published as complete components.
- Root streams clean up FIFOs safely, serialize access globally and handle
  abort/drain failures without leaving stale state.
- SMS/MMS, unsupported ROM services, raw Wi-Fi/root-module payloads and
  unknown preferences are reported as archive-only rather than restored
  speculatively.
- CI validates protocol schemas, Android lint/unit tests and Rust formatting,
  tests and Clippy alongside the desktop test suite.

## Validation

- Protocol v1 and v2 schemas validate locally.
- Full release artifacts are built and signed by the GitHub release workflow.

Cross-ROM restores remain intentionally conservative. Android Keystore/TEE
credentials, Wallet and DRM tokens, eSIM data and hardware-bound passkeys must
be provisioned again on the target device.

## Русский

- Добавлены manifest v2, типизированные CE/DE/external/OBB-компоненты,
  совместимость по ROM и подробные результаты проверки каждого компонента.
- Root-restore теперь транзакционный: журнал, BLAKE3-проверка, read-back и
  rollback при ошибке.
- Добавлены обои, контакты/журнал вызовов, locale и осторожное восстановление
  темы только для совместимой ROM.
- Неизвестные или небезопасные данные честно остаются archive-only. Полная
  сборка и подпись артефактов выполняются GitHub release workflow.
