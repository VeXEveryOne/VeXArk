# VeXArk 0.7.0 — Fast Wi-Fi media transfer

VeXArk 0.7.0 removes the application-side bottleneck from large no-root photo
and video exports.

## Highlights

- **Fast Wi-Fi:** ADB remains the trusted control channel while media bytes can
  use a temporary encrypted local-network connection.
- **Automatic selection:** VeXArk briefly tests ADB, Fast Wi-Fi and the
  destination drive, then chooses the fastest useful path.
- **Parallel copy:** up to four files are transferred concurrently, with the
  worker count reduced automatically for slower drives.
- **Resume:** interrupted files continue from `.vexark.part` data instead of
  starting from zero.
- **Integrity:** every transferred range is checked with SHA-256 before the file
  is published.
- **Live diagnostics:** the Desktop shows transport, MB/s, disk speed, progress,
  ETA and active workers.

Fast Wi-Fi uses AES-256-GCM, per-worker HKDF-SHA256 keys and replay-protected
record counters. The Android listener is read-only, accepts only MediaStore
photo/video URIs and closes after the operation or 30 seconds of inactivity.

USB 2.0 remains physically limited and will normally stay near 25–35 MB/s.
A good local Wi-Fi connection and fast destination drive can go substantially
faster, but actual throughput still depends on the phone, access point and PC.

## Русский

VeXArk 0.7.0 ускоряет копирование фото и видео без root. ADB используется для
сопряжения и управления, а сами данные при возможности передаются через
временный зашифрованный Fast Wi-Fi канал.

Перед началом приложение проверяет скорость ADB, локальной сети и диска,
автоматически выбирает транспорт и запускает до четырёх параллельных worker-ов.
Прерванные файлы продолжаются с сохранённого места, а каждый переданный диапазон
проверяется SHA-256.

USB 2.0 по-прежнему ограничен примерно 25–35 МБ/с. Fast Wi-Fi способен работать
заметно быстрее, если телефон, роутер и диск компьютера не являются узким местом.
